# Ecosystem
The ‘Ecosystem’ organism lets our visitors quickly scan the integration and added value between the key products and services Ultimaker offers.

## Storytelling
The organism is build to contain at least 3 items. Each item should have at least an icon and a description. Descriptions work best when using a max. of 120 characters. A link within each item is optional. A larger link with an icon below the items is optional as well. E.g. ‘Play video’

## Icon guidelines

A content manager can choose one of the items that are shipped with the Ultimaker design system. In this organism only product icons are intended to be used. If a content manager needs a different product icon which does not exists, it needs to be designed and added to the design system in order to become available.
